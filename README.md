# Созвездие — мессенджер для Android

«Созвездие» — мессенджер для рабочих задач. Он объединяет личные и групповые чаты, обмен файлами, фото и голосовыми сообщениями в одном месте. Так команда получает контролируемый канал связи, не смешивая работу с личной жизнью.

Проект собирается в APK, устанавливается на телефон и работает
с облачной базой.

---

## Что умеет приложение

**Вход и профиль**
- Регистрация по email и паролю, вход и выход.
- Сохранение сессии: после перезапуска приложение помнит пользователя.
- Проверка занятости ника при регистрации.
- Профиль: имя, ник, фотография, email и поле «о себе».
- Просмотр профиля собеседника.

**Чаты**
- Список личных чатов и групп: аватар, название, последнее сообщение,
  время и выделение непрочитанных.
- Создание личного чата с любым зарегистрированным пользователем.
- Группы до 50 человек: название, фото, участники.
- Роли: владелец, администратор, участник.
- Приглашение по короткой ссылке и вступление по коду.
- Выход из группы и удаление группы.

**Сообщения**
- Текстовые сообщения в реальном времени: приходят без кнопки «обновить».
- Ответ на конкретное сообщение.
- Реакции эмодзи.
- Удаление своего сообщения с подтверждением.
- Отметки о прочтении: одна галочка — отправлено, две — прочитано.
- Статусы «печатает…», «в сети» и время последнего входа.
- Копирование текста, разделители по дням, крупные эмодзи.

**Медиа**
- Отправка фотографии из галереи или камеры (сжатие перед загрузкой).
- Отправка файлов до 25 МБ и открытие полученного файла.
- Голосовые сообщения: запись до 5 минут и прослушивание.
- Аватары пользователей и групп.

**Удобство**
- Поиск по чатам и по сохранённой истории сообщений.
- Светлая, тёмная тема и тема «как в системе».
- Обои для каждого чата: готовые градиенты или своё фото.
- Черновики сообщений.
- Локальная история: переписка открывается и без интернета.

## Как это работает

Приложение построено по схеме **MVVM + Repository**:

```
Экран (Jetpack Compose)
        ↓ нажатия и ввод
ViewModel (состояние экрана)
        ↓ запросы
Repository (правила работы с данными)
        ↓
Firebase Auth + Realtime Database + Room + Supabase Storage
```

- **Экран** только показывает данные и сообщает о нажатиях.
- **ViewModel** хранит состояние, переживает поворот экрана и вызывает
  репозитории.
- **Репозиторий** решает, откуда взять данные: из облака, из локальной
  базы или из хранилища файлов.

### Путь сообщения

1. Пользователь вводит текст и нажимает «Отправить».
2. Сообщение сразу сохраняется в Room со статусом «отправляется».
3. Затем уходит в Firebase Realtime Database.
4. Firebase проверяет правила: участник ли это чата, совпадает ли автор.
5. У собеседника срабатывает слушатель, сообщение попадает в Room и на экран.
6. Экран перерисовывается, сообщение появляется в диалоге.

Фотографии и файлы сначала загружаются в Supabase Storage. В сообщении
хранится ссылка на файл, а не сам файл, поэтому база остаётся лёгкой.

## Где хранятся данные

| Место | Что хранит | Зачем |
|---|---|---|
| Firebase Realtime Database | пользователей, чаты, сообщения, статусы | обмен данными между устройствами |
| Room | копию чатов и сообщений | офлайн и быстрый запуск |
| Supabase Storage | фотографии, файлы, голосовые | тяжёлые файлы отдельно от базы |

Основные узлы Firebase:

```
users/{uid}                 профиль пользователя
usernames/{ник}             справочник «ник → uid»
presence/{uid}              в сети, последний вход, печатает
chats/{chatId}              чат: участники, роли, последнее сообщение
messages/{chatId}/{msgId}   сообщения чата
userChats/{uid}/{chatId}    чаты пользователя
groupLinks/{код}            ссылка-приглашение
groupInvites/{uid}/{chatId} приглашения
```

Сообщения лежат отдельно от чата, потому что чат читается часто и целиком,
а сообщений может быть много. Список чатов берёт только последнее
сообщение, а не всю переписку.

## Безопасность

- Пароли обрабатывает Firebase Authentication. Приложение их не хранит.
- Правила Firebase (`firebase/database.rules.json`) проверяются на сервере:
  - читать чат может только его участник;
  - писать сообщение можно только от своего имени;
  - удалять сообщение может только автор;
  - управлять группой могут только владелец и администратор.
- В приложении запрошены только два разрешения: интернет и микрофон.
- `android:allowBackup="false"` запрещает автоматическое копирование данных.
- Файлы открываются через `FileProvider`, без доступа ко всей памяти.

Открытый ключ Supabase (`anon key`) лежит в `supabase.properties`. Это не
секрет: он всё равно попадает внутрь каждого APK. Закрытые служебные ключи
в репозиторий не добавляются.

## Структура проекта

```
app/            главный экран, навигация, сборка всех модулей
core/model/     модели данных: User, Chat, Message
core/data/      Firebase, Room, Supabase, репозитории
core/ui/        общие компоненты, тема, время, обои
feature/auth/   вход и регистрация
feature/chats/  список чатов и создание нового чата
feature/chat/   диалог, группа, голосовые, обои
feature/media/  выбор и просмотр фото и файлов
feature/motion/ анимации
feature/profile/профиль и настройки
feature/search/ поиск
firebase/       правила доступа к базе
```

Правило проекта: `feature` зависит от `core`, но не от другой `feature`.
Так модули остаются независимыми, и разные люди могут работать
в разных папках.

## Запуск на Android смартфон

Установите apk\sozvezdie-messenger.apk на Android смартфон и запустите.

## Запуск через Android Studio

Проект готов к работе сразу после клонирования. Создавать файлы с ключами
и настраивать Supabase вручную не нужно: адрес и открытый ключ лежат
в `supabase.properties`.

1. Установите Android Studio.
2. Откройте папку проекта: **File → Open**.
3. Дождитесь окончания синхронизации Gradle.
4. Нажмите **Run**

Android Studio сама создаст `local.properties` с путём к Android SDK.
В Git этого файла нет, потому что путь у каждого компьютера свой.

### Сборка из командной строки

```bash
gradlew.bat assembleDebug
```

На macOS и Linux:

```bash
./gradlew assembleDebug
```

Готовый APK появится в `app/build/outputs/apk/debug/app-debug.apk`.
Для сборки нужны JDK 17 и Android SDK 35.

### Тесты

```bash
gradlew.bat :core:model:testDebugUnitTest
```

Пять простых тестов проверяют поиск и разбор ссылки группы.
Телефон и интернет для них не нужны.
